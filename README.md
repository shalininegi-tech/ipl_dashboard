PROJECT OVERVIEW:
This project is an Indian Premier League(IPL) Analysis Dashboard created using Microsoft Excel. The dashboard provides an interactive view of IPL statistics, team performance, player performance, and match-related insights.

KEY FEATURES:
IPL season-wise analysis from 2008 onwards.
Season Winner, Runner-up, Player of the series.
Analysis of toss decision and match -winning percentage.
Top 10 venues based on matches won by batting and fielding teams.
Title Winners analysis.
Top 10 Man Of The Match (MOM) award winners.
Interactive dashboard with charts and visualisations.
KPI -based presentation for quick analysis.

TOOLS & TECHNIQUES USED:
Microsoft Excel
Pivot Tables
Pivot Charts
Slicers
Excel formulas
Data Cleaning and transformation
Dashboard design and visualisation

OBJECTIVE:
The objective of this project is to analyze IPL historical data and present meaningful insights about teams, players, venues, 
toss decisions, and match outcomes through an interactive and easy-to-understand dashboard.

DATA SOURCE:
The dataset used for this IPL Dashboard was obtained from an online IPL historical dataset and contains information related to matches , teams, venues, toss decisions, winners, and player awards.

The dashboard was created by following a You tube tutorial for learning and practice purposes. The dashboard design and analyses were recreated independentaly in Microsoft Excel.


DASHBOARD PREVIEW:
The dashboard provides a consolidated view of important IPL statistics and allows users to explore different seasons and performance metrics.
